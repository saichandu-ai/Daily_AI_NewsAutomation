Daily AI News Automation 🤖

An AI-powered daily news automation workflow built using n8n, Google Gemini, RSS feeds, and Gmail.

🚀 Features

- Automatically triggers every day at 7:00 AM.
- Collects AI-related updates from RSS feeds.
- Processes and organizes content using an AI-powered workflow.
- Delivers updates directly to Gmail.

🛠️ Technologies Used

- n8n
- Google Gemini
- RSS Feeds
- Gmail

⚙️ Workflow

Schedule Trigger → RSS Read → Limit → Aggregate → Basic LLM Chain → Gmail

📚 What I Learned

- Workflow automation
- AI model integration
- RSS feed processing
- Email automation

▶️ How to Use

1. Download the workflow JSON file from this repository.
2. Import it into your n8n instance.
3. Configure your own Google Gemini and Gmail credentials.
4. Verify the schedule and timezone.
5. Test the workflow before activating it.

Note: Credentials are not included. Configure your own credentials before running the workflow.
